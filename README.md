# Express’Arte Studio V7.3.2 — Copilot SDK

## Comece pelo Windows

Execute `INICIAR_EXPRESSARTE_WINDOWS.bat` após extrair o ZIP. Consulte `LEIA_PRIMEIRO_V7_3_2_WINDOWS.txt`.

**IA GitHub Copilot é opcional:** instale via `INSTALAR_COPILOT_WINDOWS.bat`, faça login pelo GitHub Copilot CLI oficial e selecione Copilot no painel direito do Studio. Guia: `COPILOT_COMO_CONECTAR.md`.

O servidor mantém Studio 3D, site/catálogo, comunidade, calculadora, Blender Bridge e Mesh Doctor; continua apenas no `127.0.0.1`. Projetos já salvos permanecem fora do ZIP, em `%LOCALAPPDATA%\ExpressArteStudio\dados` no Windows.

Copilot conversa e sugere orientações, **não executa comandos nem edita malhas nesta versão**. Nenhuma autenticação de terceiros vem no ZIP.

Leia `RELATORIO_V7_3_2_COPILOT_TESTES.md` para testes e limites.
