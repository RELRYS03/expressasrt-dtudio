Sobre o OpenClaude

O OpenClaude é um CLI de agente de codificação open-source que roda no seu terminal e se conecta a qualquer modelo: OpenAI, Gemini, Ollama, GitHub Models e mais de 200 provedores. Uma instalação, todos os provedores.

Ver Repositório Original

Recursos Principais

  • Multi-Modelo: Suporte nativo para OpenAI, Gemini, Ollama e backends locais.
  • Ferramentas Integradas: Prompts, ferramentas, agentes, MCP e comandos slash.
  • Terminal-First: Fluxo de trabalho focado na linha de comando com saída em streaming.

Integração com Express'Arte

Esta seção foi adaptada com a paleta de cores Café e Bege do Express'Arte Studio. O código-fonte original foi analisado e seus componentes visuais foram integrados para manter a consistência da nossa oficina digital.
